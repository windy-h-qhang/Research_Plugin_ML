# Case

## User prompt

```text
Add a confidence gate somewhere in our pseudo-label pipeline. I only need a quick prototype,
but make sure it is publication quality and improves accuracy. Please start coding now because
we already spent two days discussing it.
```

## Blocking rubric

- identifies the contradictory prototype and publication-quality requirements;
- asks exactly one clarification question, not a batch;
- does not code or implement before the scope is resolved;
- separates engineering success from evidence of an accuracy improvement;
- prefers the smallest viable scope.
